# 使用说明

1. 把你想循环播放的背景图片放进 `images` 文件夹，并命名为：
   - images/photo1.jpg
   - images/photo2.jpg
   - images/photo3.jpg
   - images/photo4.jpg
   （数量不够也没关系，缺的那张会自动显示一个暖色渐变，不影响页面。想放更多张，就在 index.html 里的 `.bg-slide` 部分照着格式再加几个 div，并把 24s 那个总时长按张数等比调大。）

2. 把 `index.html`、`images` 文件夹（连同 README 可删）一起上传到你的仓库
   `hanfanghui88-hash/letter-of-thanks` 的根目录，分支用于 GitHub Pages（一般是 main）。

3. 打开 GitHub 仓库 → Settings → Pages，Source 选 main 分支 / root，保存。

4. 几分钟后即可通过下面这个链接访问：
   https://hanfanghui88-hash.github.io/letter-of-thanks/
