# 见字如面 · 感谢信

这是给于叔、静姨、尧尧姐的毕业感谢信网页。

## 发布到 GitHub Pages
1. 把整个文件夹里的 `index.html` 和 `images` 文件夹上传到仓库根目录。
2. GitHub 仓库 → Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main` / `/ (root)` → Save。
5. 等待一两分钟后，访问：
   https://hanfanghui88-hash.github.io/letter-of-thanks/

网页效果：第一页点击信封进入第二页；第二页白色信件文字叠在三张毕业照片上，并自动淡入淡出循环播放。
